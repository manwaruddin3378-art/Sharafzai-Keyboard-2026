# SUNDUS – سندس (Keyboard-only Android App)

**جوړوونکی:** د مفتي محمد انوارالدين شرفزي لخوا

SUNDUS یوازې د Android لپاره یو څوژبی، آفلاین او د محرمیت ساتونکی کیبورډ اپلیکیشن دی. په دې پروژه کې هېڅ جلا وسیله، کیلکولیټر، کلیندر، الارم یا بل غیرکیبورډي ماډیول نه شاملېږي.

## د کیبورډ ځانګړنې

- څلور ژبې: پښتو، دري، عربي او انګلیسي.
- د ژبو چټک بدلون، د تڼیو پنځه اندازې او ۴۸ رنګیزې موضوعګانې.
- د ګلانو نرم شالید، تیاره شین ـ آبي سرلیک او درې‌بعدي/سیوري لرونکې تڼۍ.
- د پورته برخې غټ، رنګین او په نوبت بدلېدونکي اذکار.
- د حرکاتو، ایموجي، نښو او اسلامي/ورځنیو چمتو جملو برخې.
- کلیپ‌بورډ: کاپي، کټ، پېسټ، ټول انتخاب، تاریخچه، خوښ شوي متنونه او لټون.
- شخصي قاموس، د کلمو وړاندیزونه، AutoText لنډیزونه او د ایمیل چټک داخلول.
- د غږ له لارې لیکل، د Android د غږ پېژندنې خدمت په مرسته.
- د انتخاب شوي متن د حذف لپاره د Backspace اصلاح شوې کړنه.
- د انګلیسي جملې په پیل کې اتومات لوی توری؛ وړاندیزونه د کاروونکي په خوښه منل کېږي او متن په خپله نه بدلوي.

## آفلاین او محرمیت

- د Android Manifest کې د INTERNET اجازه نشته.
- عادي ټایپ شوی متن نه ثبتېږي؛ یوازې هغه لغتونه او جملې چې کاروونکی یې په خپله په څرګنده توګه خوندي کوي، په موبایل کې ساتل کېږي.
- د مایکروفون اجازه یوازې د کاروونکي په غوښتنه د غږیز لیکلو لپاره کارېږي.
- د غږ پېژندنې آفلاین فعالیت د موبایل د غږ پېژندنې اپ او د اړوندې ژبې د نصب شوې آفلاین بستې پورې تړلی دی.
- د وړاندیزونو لغتونه اوس بنسټیز آفلاین لغتونه او د کاروونکي شخصي لغتونه دي؛ دا د مسلکي بشپړ املا-سموونکي بدیل نه دی.

## تخنیکي معلومات

- Application ID: com.sharafzai.keyboard
- Version: 1.6 (versionCode 11)
- Minimum Android: API 21 (Android 5.0)
- Target Android: API 34
- Release APK د GitHub Actions له لارې د پروژې د خصوصي لاسلیک کېلي په کارولو جوړېږي.
- د Android په تنظیماتو کې د کیبورډ فعالول او انتخابول د کاروونکي له خوا ترسره کېږي.
- د وروستي موبایل-محور ازمېښت لپاره باید APK په مناسب Android موبایل کې یو ځل نصب او وازمویل شي.
