# SUNDUS – سندس (Keyboard-only Android App)

**جوړوونکی:** د مفتي محمد انوارالدين شرفزي لخوا

SUNDUS یوازې د Android لپاره یو څوژبی، آفلاین او د محرمیت ساتونکی کیبورډ اپلیکیشن دی. په دې پروژه کې هېڅ جلا وسیله، کیلکولیټر، کلیندر، الارم یا بل غیرکیبورډي ماډیول نه شاملېږي.

## د کیبورډ ځانګړنې

- څلور ژبې: پښتو، دري، عربي او انګلیسي.
- د ژبو چټک بدلون، د تڼیو پنځه اندازې او ۴۸ رنګیزې موضوعګانې.
- د ګلانو نرم شالید، تیاره شین ـ آبي سرلیک او درې‌بعدي/سیوري لرونکې تڼۍ.
- د پورته برخې غټ، رنګین او په نوبت بدلېدونکي اذکار؛ د اسلامي ایموجي پراخه برخه.
- د سندس لوګو، د ژبو انتخاب، ایموجي، د اسلامي جملو برخه، د ۴۸ رنګونو انتخاب او تنظیمات.
- د ښکته اصلي قطار کې ۱۲۳ د شمېرو قطار ښکاره/پټوي؛ د سندس لوګو تڼۍ فاصله ورکوي او AutoText لنډیز پراخوي؛ «پټول» کیبورډ بندوي؛ ورپسې کامه، ټکی او Enter دي.
- شخصي جملې اوس اضافه، اصلاح او حذف کېدای شي؛ د کیبورډ په محدود قد کې د جملو برخه؛ په پښتو، دري، عربي او انګلیسي کې له ۶۰ څخه زیاتې جملې، اوږدې جملې او د مخکیني/راتلونکي غشي له لارې بدلون.
- د حرکاتو، ایموجي او نښو برخې؛ د چټکو تڼیو په قطار کې کلیپ‌بورډ، AutoText، قاموس، غږیز لیکل او رنګ بدلول.
- د شخصي آفلاین ژباړې برخه: د کاروونکي له خوا ثبت شوې کلمې او جملې بې له انټرنېټه لټوي؛ ثبت شوې ژباړې اداره، اصلاح او حذف کېدای شي؛ دا لا ماشیني ژباړن نه دی.
- د ژباړې بشپړ آفلاین ماشین لا نه دی ورزیات شوی؛ د دې لپاره د څو ژبو د ژباړې محلي ډیټا/ماډل ته اړتیا ده، نو د تڼۍ شتون د بشپړ ژباړن معنا نه لري.
- کلیپ‌بورډ: کاپي، کټ، پېسټ، ټول انتخاب او د کاروونکي په غوښتنه د خوښې متنونه خوندي کول؛ خوندي شوي متنونه بېرته داخلول او حذف کولای شئ؛ د عادي کلیپ‌بورډ تاریخچه نه ساتل کېږي.
- پراخ شوي آفلاین لغتونه، شخصي قاموس چې کاروونکی پکې کلمه او خپله مانا/تشریح ثبت، اصلاح، لټون او حذف کولای شي؛ د کلمې د نوم د اصلاح پر مهال پخوانۍ کلمه هم سم مدیریت کېږي؛ د عربي‌لیکدود د ځینو بڼو د پېژندلو وړاندیزونه، AutoText لنډیزونه چې اداره، اصلاح او حذف کېدای شي، او د ایمیل چټک داخلول.
- د غږ له لارې لیکل، د Android د غږ پېژندنې خدمت په مرسته؛ د تڼیو غږ او رپ د ځانګړو تڼیو په ګډون د فعالولو/بندولو اختیار لري.
- د انتخاب شوي متن د حذف لپاره د Backspace اصلاح شوې کړنه.
- د انګلیسي جملې په پیل کې اتومات لوی توری؛ وړاندیزونه د کاروونکي په خوښه منل کېږي او متن په خپله نه بدلوي.

## آفلاین او محرمیت

- د Android Manifest کې د INTERNET اجازه نشته.
- عادي ټایپ شوی متن نه ثبتېږي؛ یوازې هغه لغتونه او جملې چې کاروونکی یې په خپله په څرګنده توګه خوندي کوي، په موبایل کې ساتل کېږي.
- د مایکروفون اجازه یوازې د کاروونکي په غوښتنه د غږیز لیکلو لپاره کارېږي.
- د غږ پېژندنې آفلاین فعالیت د موبایل د غږ پېژندنې اپ او د اړوندې ژبې د نصب شوې آفلاین بستې پورې تړلی دی.
- د وړاندیزونو لغتونه بنسټیز او پراخ شوي آفلاین لغتونه او د کاروونکي شخصي لغتونه دي؛ دا لا هم د مسلکي بشپړ املا-سموونکي بدیل نه دی.

## تخنیکي معلومات

- Application ID: com.sharafzai.keyboard
- Version: 1.12 (versionCode 17)
- Minimum Android: API 21 (Android 5.0)
- Target Android: API 34
- Release APK د GitHub Actions له لارې د پروژې د خصوصي لاسلیک کېلي په کارولو جوړېږي.
- د Android په تنظیماتو کې د کیبورډ فعالول او انتخابول د کاروونکي له خوا ترسره کېږي.
- د وروستي موبایل-محور ازمېښت لپاره به د کاروونکي له نصب وروسته د اصلي وسیلې پر بنسټ ارزونه ترسره کېږي.
